## 2. 请求拦截器 `已验证`

每次请求自动注入以下请求头：

```js
api.interceptors.request.use(async (config) => {
  config.headers["x-platform"] = "web";
  config.headers["x-version"]  = "999.0.0";           // 固定版本号
  config.headers["x-language"] = "en";                 // 默认
  const loc = getCurrentLocale();                      // 从路径/cookie/navigator 推断
  if (loc) config.headers["x-language"] = loc;

  const token = TokenUtils.getToken();
  if (token) config.headers["x-auth-token"] = token;   // 认证头

  const finger = Finger.getFinger();
  if (finger) config.headers["x-finger"] = finger;     // 设备指纹

  return cfg.customRequestInterceptor
    ? await cfg.customRequestInterceptor(config)
    : config;
});
```

### 请求头清单 `已验证`

| 头 | 值 | 说明 |
|----|----|----|
| `x-platform` | `web` | 客户端平台 |
| `x-version` | `999.0.0` | 前端版本（固定） |
| `x-language` | `en` / locale | 语言，随当前 locale |
| `x-auth-token` | `<jwt>` | 登录令牌（裸 token，非 Bearer） |
| `x-finger` | `<visitorId>` | FingerprintJS 设备指纹 |
| `Content-Type` | `application/json` | 写操作 |
| `x-no-handle` | `true` | **禁用统一错误处理**（见 §4） |
| `x-no-show-msg-handle` | (存在即生效) | 500 错误时不弹提示（见 §4） |

> OpenAPI 客户端内部还会通过 `YS(headers, "x-auth-token", cfg)` 显式注入 token；部分接口额外传 `x-platform` 作为 query（如 `getFeature`、`getTemplatesByScene`）。

## 3. 统一响应封装 `已验证`

**所有接口**返回统一信封：

```jsonc
{
  "code": "200",          // 字符串！成功 = "200"
  "data": { ... },        // 业务数据，失败时可空
  "msg": "错误描述",       // 失败时的用户可读信息
  "fieldErrors": [        // 字段级校验错误（表单场景）
    { "field": "email", "message": "..." }
  ]
}
```

### 双码体系（重要）`静态确认`

平台存在**两套成功码**，取决于接口类型：

| 场景 | 成功码 | 类型 | 说明 |
|------|--------|------|------|
| 普通查询/操作（auth/home/models…） | `"200"` | 字符串 | 由 axios 响应拦截器统一判定 |
| **异步任务提交**（create/lipSync/motion/audio create…） | `1` | 数字 | 在业务代码中单独判定，且常伴随 `resultId` |
| 业务失败（积分/审核/限流…） | 负数 `-1 ~ -6` | 数字 | 见 08 文档 |

> 提交类接口成功示例（`5142`）：
> ```js
> if (S?.code === 1 && S?.resultId) { /* 提交成功 */ }
> ```
> 说明异步任务接口**不**走 `"200"` 判定，而是直接读 `data.code === 1`。

## 4. 响应拦截器与错误处理 `已验证`

```js
api.interceptors.response.use(
  (response) => {
    // 1) 若请求头带 x-no-handle → 原样返回，交给调用方自行处理
    if (response.config.headers.has(NO_HANDLE)) return response.data;

    const { data, status } = response;
    if (data && data.code) {
      const { code, fieldErrors } = data;

      if (code === "200") return data;                       // 成功：返回整个信封

      if (code === "400") {                                  // 参数错误
        let msg = data.msg || "Request params error";
        if (fieldErrors?.length) msg = fieldErrors[0].message;
        toast(msg); throw new ApiError(msg, code, status, fieldErrors, data);
      }
      if (code === "401") {                                  // 未认证
        toast("Authentication failed");
        TokenUtils.clearToken();                             // 清除 token
        window.location.href = "/";                          // 跳首页
        throw new ApiError("Authentication failed", code, status, fieldErrors, data);
      }
      if (code === "403") {                                  // 无权限
        toast("Access forbidden");
        throw new ApiError("Access forbidden", code, status, fieldErrors, data);
      }
      if (code === "500") {                                  // 服务端错误
        const msg = data.msg || "Internal server error";
        if ("x-no-show-msg-handle" in response.config.headers)
          throw new ApiError(msg, code, status, fieldErrors, data);   // 不弹提示
        toast(msg);
        throw new ApiError(msg, code, status, fieldErrors, data);
      }
    }
    // 无 code 字段
    const msg = data?.msg || "Request Unknown error";
    toast(msg);
    throw new ApiError(msg, "500", status, [], data);
  },
  (error) => {
    console.warn("[API Response Error]", error);
    if (!error.response || error.response.status !== 200) {
      const msg = "Network error or server is unreachable";
      toast(msg);
      throw new ApiError(msg, "500", error.status, [], error.response?.data);
    }
  }
);
```

### 关键行为总结 `已验证`

| 触发条件 | 行为 |
|---------|------|
| 请求头含 `x-no-handle` | 跳过所有统一处理，原样返回 `response.data` |
| `code === "200"` | 返回信封 `data`（含 `code/data/msg`） |
| `code === "400"` | 弹 toast（优先 `fieldErrors[0].message`），抛 `ApiError` |
| `code === "401"` | 弹提示 → **清除 token** → **强制跳首页** |
| `code === "403"` | 弹 "Access forbidden" |
| `code === "500"` | 弹 `msg`（若带 `x-no-show-msg-handle` 则不弹），抛错 |
| 网络异常 / 非 200 HTTP | 弹 "Network error or server is unreachable" |

### 错误对象 `ApiError` 结构 `静态确认`
```ts
class ApiError extends Error {
  code: string;          // "400" | "401" | "403" | "500"
  status: number;        // HTTP status
  fieldErrors: { field: string; message: string }[];
  response: any;         // 原始信封
}
```

### `x-no-handle` 的用途 `静态确认`
在认证初始化、登录/注册等**需要自行精细处理错误**的场景，调用方会显式传 `{headers:{[NO_HANDLE]:"true"}}`，避免拦截器弹全局 toast 或跳转。例如：
```js
getAccount({ headers: { "x-no-handle": "true" } })
login({...}, { headers: { "x-no-handle": "true" } })
```

## 5. 认证令牌机制 `已验证`

`9689` 中的 `TokenUtils`（模块 `523`）：

| 方法 | 行为 |
|------|------|
| `getToken()` | 读 `localStorage["x-auth-token"]`，空则 null |
| `setToken(t)` | 写入 localStorage，空字符串拒绝 |
| `clearToken()` | 删除 key |
| `existToken()` / `isTokenValid()` | 判空 |
| `getBearerToken()` | 返回 `"Bearer " + token`（**注意：拦截器实际用的是裸 token，非 Bearer**） |
| `updateToken(t)` | clear + set |
| `disableGoogleAutoLogin()` / `enableGoogleAutoLogin()` | 控制 Google 自动登录开关（key `x-auth-google-auto-login`） |

### localStorage 键清单 `已验证`

| 键 | 用途 |
|----|------|
| `x-auth-token` | 登录令牌（`STORE_AUTH_KEY`） |
| `x-auth-google-auto-login` | 禁用 Google 自动登录标记 |
| `x-finger` | 设备指纹（`STORE_FINGER_KEY`） |
| `creen_last_daily_popup_date` | 每日积分弹窗「今天已显示」标记（`en-CA` 日期） |
| guest 相关键 | `guestUid` / `guestKey`（键名见 04 文档） |

## 6. 设备指纹 `已验证`

- 库：**FingerprintJS**（`@fingerprintjs/fingerprintjs`，通过 `m1.openfpcdn.io` 加载）。
- 模块 `35255`：
  ```js
  class Finger {
    static async initFinger() {
      const fp = await FingerprintJS.load();
      const r = await fp.get();
      this.setFinger(r.visitorId);
    }
    static getFinger() { return localStorage.getItem("x-finger"); }
  }
  ```
- 使用点：`layout` 初始化时 `initFinger()`；`AuthProvider` 拉账户前 `await initFinger()`；创建游客前确保已初始化。
- 透传：请求头 `x-finger`。
