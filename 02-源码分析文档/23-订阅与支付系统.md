## 4. 权益（Benefits）结构 `已验证`

`getBenefitsValue` 返回权益，前端按 `|` 分隔解析：

```js
// 格式："图片,视频,音乐,音频,音色|其它权益..."
function parseBenefits(str) {
  const [core, more] = str.split("|");
  const c = core.split(",");
  const m = more.split(",");
  return {
    coreBenefits: {
      images:            c[0] || "",   // 图像额度
      videos:            c[1] || "",   // 视频额度
      music:             c[2] || "",   // 音乐额度
      audio:             c[3] || "",   // 音频额度
      createOwnVoice:    c[4] || "",   // 自定义音色额度
      imageConcurrency:  c[5] || "",   // 图像并发
      videoConcurrency:  c[6] || "",   // 视频并发
      musicConcurrency:  c[7] || "",   // 音乐并发
      audioConcurrency:  c[8] || ""    // 音频并发
    },
    moreValues: m
  };
}
```

### 权益维度
| 维度 | 含义 |
|------|------|
| `images` | 图像生成额度 |
| `videos` | 视频生成额度 |
| `music` | 音乐生成额度 |
| `audio` | 音频生成额度 |
| `createOwnVoice` | 自定义音色额度 |
| `imageConcurrency` | 图像并发数 |
| `videoConcurrency` | 视频并发数 |
| `musicConcurrency` | 音乐并发数 |
| `audioConcurrency` | 音频并发数 |

## 14. 支付架构图 `静态确认`
