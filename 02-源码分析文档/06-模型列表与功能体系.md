## 2. 模型对象字段 Schema `静态确认`

从调用点交叉还原的模型对象字段：

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | number/string | 模型 ID |
| `name` / `title` | string | 模型名 |
| `code` | string | 模型 code |
| `type` | string | 类型 |
| `icon` | string | 图标路径（缺省 `/image/models/sora.png`） |
| `description` | string | 描述 |
| `previewImage` | string | 预览图 |
| `provider` | string | 供应商 |
| `sort` | number | 排序 |
| `status` | number | 状态 |
| `tags` | string[] | 标签 |
| `isDefault` | boolean | 是否默认模型 |
| **`integralFee`** | number | **基础积分价**（选中时立即显示） |
| **`vipLevel`** | number | **所需 VIP 等级**（0=免费，1/2/3） |
| `isSupportText` | boolean | 是否支持文本输入 |
| `isSupportImage` | boolean | 是否支持图片输入 |
| `isSupportVideo` | boolean | 是否支持视频输入 |
| `isSupportAudio` | boolean | 是否支持音频输入 |
| `promptLength` | number | 提示词长度上限（默认 3000） |
| `maxStandardImageInputCount` / `maxImageInputCount` | number | 输入图片上限（默认 3） |
| `config` | object | 模型能力配置（见下） |

### `config` 字段（决定 UI 选项与请求参数）`静态确认`

| config 字段 | 说明 |
|-------------|------|
| `resolutionOptions` | 分辨率选项 |
| `qualityOptions` | 画质选项 |
| `durationOptions` | 时长选项 |
| `aspectRatios` / `radioOptions` | 宽高比选项 |
| `backgroundOptions` | 背景选项 |
| `modeOptions` | 模式选项 |
| `characterOrientationOptions` | 人物朝向选项 |
| `supportKeepOriginalSound` | 是否支持保留原声 |
| `supportGenerateAudio` | 是否支持生成音频 |
| `supportStrength` | 是否支持强度参数 |
| `minStrength` / `maxStrength` | 强度范围 |
| `minVideoWidth` / `maxVideoWidth` | 视频宽度约束 |
| `minVideoHeight` / `maxVideoHeight` | 视频高度约束 |
| `isSupportDurationScroll` | 时长是否可滚动选择 |
| `minScrollDuration` / `maxScrollDuration` | 滚动时长范围（默认 1/15） |

> 前端大量使用 `model.config?.xxx?.length > 0` 条件渲染对应选项，并据此决定是否向 `calculateIntegral` / `create` 传参。

## 9. 模型选择与默认值 `已验证`

| 机制 | 说明 |
|------|------|
| 默认模型标记 | 模型对象 `isDefault` |
| 默认模型存储 | `localStorage["defaultImageModelId"]` / `["defaultVideoModelId"]` |
| URL 指定模型 | `?model=<id>` |
| 模型切换 | 切换时重置不兼容的选项（如 `modeOptions` 不含当前值则回退首项） |
| 模型切换积分 | 若模型带 `integralFee`，立即更新预估积分 |

模型列表加载失败兜底：
```js
const resp = await api.get("/api/aiVideo/motionControlModels");
if (resp?.code === "200" && Array.isArray(resp.data)) { setModels(resp.data); ... }
```
