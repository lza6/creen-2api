## 7. 生成结果码处理逻辑（最终版）`已验证`

各业务线的结果码分支（`5142` 统一模式）：

```js
const code = resp.data.code;

if (code === 1) {                    // 提交成功
  toast({ title: "reminder", description: "taskSubmittedSuccessfully", color: "success" });
  clearForm();
  await onSuccess();
  const newProjectId = resp.data.newProjectData?.id;
  if (newProjectId) onProjectCreated(newProjectId);
}
else if (code === -1) {              // 积分不足
  account.canAccessVip !== true
    ? (buyVipModal.open(), toast({ description: "insufficientCredits", color: "warning" }))
    : buyVipModal.open(3);
}
else if (code === -2) {              // 生成失败
  toast({ title: "error", description: "generateFailed", color: "danger" });
}
else if (code === -3) {              // 内容审核 / 任务进行中
  toast({ title: "reminder", description: "generateContentWarningError", color: "warning" });
}
else if (code === -4) {              // 任务数超限
  toast({ description: "jobCountLimitError", color: "warning" });
  (account.canAccessVip !== true || account.vipLevel < "3") && buyVipModal.open(2);
}
else if (code === -5) {              // 操作过频
  toast({ description: "aiGenerator.errors.operationTooFrequent", color: "warning" });
}
else if (code === -6) {              // 自定义音色上限（音频）
  toast({ description: "customVoiceLimitReached", color: "warning" });
  account.canAccessVip !== true ? buyVipModal.open() : buyVipModal.open(higherLevel);
}
```

## 8. 完整业务校验顺序（提交前）`已验证`

以图像生成为例：
```
1. 模型是否选中？        → pleaseSelectModel
2. 模型 vipLevel 校验    → buyVipModal.open(vipLevel)
   if (model.vipLevel > 0 && packageIntegral <= 0 && vipIntegral <= 0)
3. 图片/文本输入校验
   - isSupportImage && !isSupportText → 必须传图
   - !isSupportImage && isSupportText → 必须传文本
   - 都支持 → 至少一个
4. 提示词长度校验        → promptTooLong（promptLength ?? 3000）
5. 图片数量校验          → maxImagesReached
6. 提交
7. 结果码处理（见 §7）
```
