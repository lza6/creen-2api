## 2. 认证初始化流程 `已验证`

`AuthProvider`（`6628`）挂载时执行：

```js
useEffect(() => {
  (async () => {
    // 1. 同步游客身份（本地有则复用，无则创建）
    await GuestUtils.syncGuestInfo();
    // 2. 拉取账户信息
    await fetchAccount();
  })();
}, []);

async function fetchAccount(force) {
  await Finger.initFinger();
  if (accountInfo == null && !isLoading) {
    try {
      setLoading(true);
      const resp = await getAccount({ headers: { "x-no-handle": "true" } });
      if (resp?.data && resp.code === "200") {
        setAccountInfo(resp.data);
      } else {
        clearAccountInfo();
        TokenUtils.clearToken();
        if (!force) await guestLogin();
      }
    } catch (e) {
      clearAccountInfo();
      if (!force) { TokenUtils.clearToken(); await guestLogin(); }
    } finally { setLoading(false); }
  }
}

async function guestLogin() {
  const { guestUid, guestKey } = GuestUtils.getGuestLoginRequest();
  const resp = await authApi.loginByGuest({
    authLoginByGuestRequest: { guestUid, guestKey }
  });
  if (resp?.data.idToken) {
    TokenUtils.setToken(resp.data.idToken);
    await fetchAccount(true);
  } else {
    GuestUtils.clearGuestInfo();
    window.location.reload();
  }
}
```

## 4. 注册流程（三步）`已验证`

```
step1: 邮箱 + 密码 + Turnstile  →  POST /api/auth/regSubmit
step2: 6 位邮箱验证码            →  POST /api/auth/confirmReg   → 得 idToken
step3: 设置昵称                  →  POST /api/auth/setNickname
```

| 步骤 | 端点 | 请求体 | 校验 |
|------|------|--------|------|
| 1 | `regSubmit` | `{ email, password, confirmPassword, turnstileToken }` | 邮箱格式、密码 8–20 位、两次一致 |
| 2 | `confirmReg` | `{ email, code }` | 验证码 6 位；成功后 `setToken(idToken)`，并预填随机昵称 |
| 3 | `setNickname` | `{ nickname }` | 昵称长度 |

**重发验证码**：`POST /api/auth/resendRegCode { email }`（60 秒倒计时）
**随机昵称**：`GET /api/auth/randomNickname`（失败时前端本地兜底：`["Creener","AI_Explorer","Novel_Maker","ChatBuddy","Dream_Weaver","Cyber_Companion"]` + 随机数）

## 5. 找回密码流程（三步）`已验证`

```
step1: 输入邮箱          →  POST /api/auth/sendResetPwdCode { email }
step2: 输入验证码        →  POST /api/auth/verifyResetPwdCode { email, code }  → 返回布尔
step3: 设置新密码        →  POST /api/auth/resetPassword { email, code, newPwd, confirmPwd }
```

新密码规则：8–20 位，两次一致。

## 6. 令牌（Token）机制 `已验证`

### 6.1 TokenUtils 方法表

| 方法 | 行为 |
|------|------|
| `getToken()` | 读 `localStorage["x-auth-token"]` |
| `setToken(t)` | 写入（空值拒绝） |
| `clearToken()` | 删除 |
| `existToken()` / `isTokenValid()` | 判空 |
| `getBearerToken()` | `"Bearer " + token`（**请求实际未用 Bearer**） |
| `extractTokenFromBearer(t)` | 剥离 `"Bearer "` 前缀 |
| `updateToken(t)` | clear + set |
| `disableGoogleAutoLogin()` | 写 `x-auth-google-auto-login = "true"` |
| `enableGoogleAutoLogin()` | 删除该键 |
| `isDisabledGoogleAutoLogin()` | 判断该键存在 |

### 6.2 传输
- **存储键**：`localStorage["x-auth-token"]`
- **请求头名**：`x-auth-token`（**裸 token，非 Bearer**）
- 由请求拦截器自动注入（见 02 文档）

### 6.3 失效处理
`401` 响应 → 弹提示 → `clearToken()` → `window.location.href = "/"`（见 02 文档）。

## 10. 每日免费积分 `已验证`

### 10.1 领取
```js
// store action
claimDayFreeIntegral: async () => {
  const api = new AuthControllerApi(undefined, undefined, axios);
  return (await api.claimDayFreeIntegral()).data;   // GET /api/auth/claimDayFreeIntegral
}
```

### 10.2 自动弹窗
```js
useEffect(() => {
  if (!accountInfo || accountInfo.isGuest === true || !accountInfo.email) return;
  const today = new Date().toLocaleDateString("en-CA");           // YYYY-MM-DD
  const last = localStorage.getItem("creen_last_daily_popup_date");
  if (last !== today && accountInfo.canGetDayFreeIntegral === true) {
    setTimeout(() => open(), 300);
  }
}, [accountInfo]);
```
- 领取成功后写 `localStorage["creen_last_daily_popup_date"] = today` 并 `refreshAccountInfo()`
- 弹窗 UI 硬编码显示 **"+100"**
- 按钮禁用条件：`!isGuest && canGetDayFreeIntegral === false`

### 10.3 倒计时
```js
const base = accountInfo.requestCurrentTime
  ? new Date(accountInfo.requestCurrentTime).getTime() : NaN;
const remain = () => {
  const sec = accountInfo.dayIntegralExpireSeconds || 0;
  if (!sec) return 0;
  return Number.isNaN(base) ? sec
    : Math.max(sec - Math.floor((Date.now() - base) / 1000), 0);
};
// 每秒递减；进度条 maxValue = 86400（24 小时）
// 归零后触发一次 refreshAccountInfo()
```
展示格式：`new Date(1000 * remain).toISOString().slice(11,19)` → `HH:MM:SS`

## 14. 认证流程总图

```
mount
 ├─ Finger.initFinger()                          # 指纹
 ├─ GuestUtils.syncGuestInfo()                   # 游客身份（无则 createGuest）
 └─ fetchAccount()
     ├─ code==="200" → setAccountInfo(data)
     └─ 失败 → clearToken() → guestLogin()
                    ├─ 有 idToken → setToken → fetchAccount(true)
                    └─ 无 idToken → clearGuestInfo() → reload()

用户登录（login / loginByGoogle / loginByApple / regSubmit+confirmReg）
 └─ data.idToken → setToken → disableGoogleAutoLogin() → 刷新账户

登出 → clearToken + clearGuestInfo + enableGoogleAutoLogin → reload "/"
```
