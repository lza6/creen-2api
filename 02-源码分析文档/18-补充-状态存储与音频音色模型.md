## 2. `ai-generator-store` 完整定义 `已验证`

### 2.1 初始 state
```js
{
  activeTab: "image",
  activeVideoSubTab: "create",
  pendingVideoData: null,
  pendingImageData: null,
  pendingComicData: null,
  pendingMediaData: null,
  pendingMotionData: null,
  pendingAudioData: null,
  pendingVideoEditorData: null,
  pendingLipSyncData: null,
  pendingTalkingAvatarData: null,
  handleGlobalFileDrop: null,
  handleSubTabFileDrop: null,
  showExplore: true
}
```

### 2.2 Actions（全部）
| Action | 行为 |
|--------|------|
| `setActiveTab(tab)` | 切主 Tab；`"motion_control"` 特殊映射为 `video` + 子 Tab |
| `setActiveVideoSubTab(t)` | 切视频子 Tab |
| `setShowExplore(b)` | 显示/隐藏探索区 |
| `fillVideoData(d)` | 切到 `video/create`，填 `pendingVideoData`，清其它 pending |
| `fillImageData(d)` | 切到 `image`，填 `pendingImageData` |
| `fillMotionData(d)` | 切到 `video/motion_control`，填 `pendingMotionData` |
| `fillAudioData(d)` | 切到 `audio`，填 `pendingAudioData` |
| `fillMediaData(d)` | 填 `pendingMediaData` |
| `fillComicData(d)` | 切到 `comic`，填 `pendingComicData` |
| `fillVideoEditorData(d)` | 切到 `video_editor`，填 `pendingVideoEditorData` |
| `fillLipSyncData(d)` | 切到 `video/lip_sync`，填 `pendingLipSyncData` |
| `fillTalkingAvatarData(d)` | 切到 `video/talking_avatar`，填 `pendingTalkingAvatarData` |
| `clearPendingData()` | 清空全部 pending |

> **关键模式**：每个 `fill*Data` 在设置自己的 pending 时会**清空其它 pending**，保证同一时刻只有一个待处理数据。

### 2.3 用途
「从灵感墙/资产库点击『创建相似』」→ 调用对应 `fill*Data` → 跳转到工作台并预填。

## 3. `account-store` 完整定义 `静态确认`

位置：`9689` 模块 `52852`

### 3.1 State
```js
{
  accountInfo: null,      // 账户信息对象
  isLoading: false,
  error: null,
  isDailyPopupOpen: false
}
```

### 3.2 Actions
| Action | 行为 |
|--------|------|
| `setAccountInfo(data)` | 设置账户 |
| `clearAccountInfo()` | 清空账户 |
| `setLoading(b)` | 加载态 |
| `setError(e)` | 错误 |
| `reset()` | 重置 |
| `setIsDailyPopupOpen(b)` | 每日弹窗开关 |
| `claimDayFreeIntegral()` | 领取每日积分 |
| `refreshAccountInfo()` | 刷新账户（带去重 Promise） |
| `deleteAccount()` | 注销 |

### 3.3 导出的 Hook
```js
useAccountStore()        // E1 - 完整 store
getAccountDedup()        // OW - 去重版 getAccount
useAccountInfo()         // T4 - 仅 accountInfo
useSetDailyPopup()       // b$ - setIsDailyPopupOpen
useDailyPopupOpen()      // lu - isDailyPopupOpen
```

### 3.4 去重机制
```js
let pending = null;
const getAccount = (opts) =>
  pending || (pending = api.getAccount(opts).finally(() => pending = null));
```
并发调用共享同一 Promise。

## 8. 数据流：从灵感墙到生成 `已验证`

```
灵感墙/资产卡片
  └─ 点击「Create Similar」
       └─ 按 scene 分流：
            scene === "12" → fillMotionData({ modelId, sourceVideo })
            其它          → fillVideoData({ modelId, prompt })
                          / fillImageData({ modelId, prompt })
       └─ store 更新 activeTab + pending*Data
       └─ 工作台读取 pending*Data → 预填表单
       └─ 调 clearPendingData() 清理
```

## 9. 两个 store 的对比

| 维度 | `ai-generator-store` | `account-store` |
|------|---------------------|-----------------|
| 持久化 | 否（会话级） | 是（`persist` 包装） |
| 核心职责 | UI Tab 与待处理数据 | 用户账户与积分 |
| 更新频率 | 高（切 Tab/填数据） | 低（登录/刷新） |
| 并发处理 | 无 | 去重 Promise |
| 消费方 | 工作台 | 全站 |
