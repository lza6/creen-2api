## 18. 隐藏的角色聊天模块痕迹 `已验证`

登录成功后的跳转逻辑（`9689`，Google/Apple/邮箱登录三处一致）揭示了平台**存在（或曾存在）角色聊天模块**：

```js
const isChatPage = window.location.pathname.startsWith("/chat/")
                || window.location.pathname.startsWith("/character/chat/");
const isCreatePage = window.location.pathname.startsWith("/create");

if (isChatPage) {
  window.location.reload();                    // 聊天页 → 重载
} else if (isCreatePage) {
  const acc = await getAccount({ headers: { "x-no-handle": "true" } });
  if (acc?.data && acc.code === "200") setAccountInfo(acc.data);
  closeModal();
  window.location.href = "/";                  // 创建页 → 回首页
} else {
  const acc = await getAccount({ headers: { "x-no-handle": "true" } });
  if (acc?.data && acc.code === "200") { setAccountInfo(acc.data); closeModal(); }
}
```

### 证据链
| 证据 | 说明 |
|------|------|
| 路由 `/chat/` | 登录后特殊处理 |
| 路由 `/character/chat/` | 登录后特殊处理 |
| `rivalKeywords` | `c.ai, joyland ai, candy ai, spicychat ai, polybuzz ai, crushon ai, spicy ai, gpt girlfriend` |
| `apkDownloadUrl` | `ChatUp-Sex Chat & Image & Video.apk`（成人向 App） |
| 公司名 | CODESAIL LIMITED |

### 推断 `合理推断`
平台可能：
1. **曾是一个角色聊天（AI companion）产品**，后转向 AI 图像/视频生成，聊天路由残留；
2. 或**在其它域名/App 提供聊天产品**，共用同一套账户与登录体系。

> 当前采集的前端 chunk 中**未包含**聊天页面组件（对应 chunk 未下载），故聊天功能的具体实现不可见。
