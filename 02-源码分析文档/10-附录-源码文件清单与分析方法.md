# 10 — 附录：源码文件清单与分析方法

## 1. 分析方法说明

本分析针对 **Next.js 生产构建产物**（webpack minified），采用以下手段：

| 手段 | 说明 |
|------|------|
| 字符串提取 | `grep -oE '"/api/[^"]*"'` 提取全部端点路径 |
| 调用点切片 | 用 Node 脚本按偏移量截取函数体，还原请求参数构造 |
| OpenAPI 还原 | 识别 `(0,X.WC)("opName","RequestType",t)` 模式还原操作名与请求体类型 |
| 交叉印证 | 同一常量在多文件出现即判定为 `静态确认` |
| 符号追踪 | 追踪 `integral`、`code`、`model` 等关键字的全部使用点 |

## 5. 复现方法

如需自行复核，可在 `源代码/` 目录执行：

```bash
# 1. 提取全部 API 路径
grep -oE '"/api/[^"]*"' *.js | sort -u

# 2. 提取所有请求头
grep -ohE 'headers\["[a-z-]+"\]|headers\."?[a-z-]+"?=' *.js | sort -u

# 3. 提取 OpenAPI 操作名与请求体类型
node -e "const s=require('fs').readFileSync('7747-f79fca7a78bd15bd.js','utf8');
let re=/\(0,l\.WC\)\.\(\"([a-zA-Z0-9_]+)\",\"?([a-zA-Z0-9_]*)\"?/g,m;
while((m=re.exec(s)))console.log(m[1],m[2])"

# 4. 提取 localStorage 键
grep -ohE 'localStorage\.(get|set|remove)Item\("[^"]+"' *.js | sort -u

# 5. 提取业务错误码
node -e "const s=require('fs').readFileSync('5142.8cc95d675e4959d0.js','utf8');
let re=/\.code\)?===(-?[0-9]{1,2})\b/g,m;while((m=re.exec(s)))console.log(m[1])"
```

## 6. 术语表

| 术语 | 含义 |
|------|------|
| Integral | 积分（平台通用货币） |
| `integralFee` | 模型单次基础积分价 |
| `vipIntegral` | VIP 专属积分池 |
| `packageIntegral` | 套餐赠送积分池 |
| `dayFreeIntegral` | 每日免费积分 |
| `x-no-handle` | 跳过统一错误处理的请求头 |
| scene | 前端工作台 Tab 场景标识 |
| resultId | 异步生成任务 ID |
| 游客（guest） | 未登录自动注册的临时账户 |
