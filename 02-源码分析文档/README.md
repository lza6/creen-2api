## 关键结论速览

- **接口风格**：OpenAPI 生成的 TS 客户端 → axios，统一 `{code, data, msg, fieldErrors}` 封装，成功码为**字符串 `"200"`**，异步任务提交成功码为**数字 `1`**，业务错误为**负数码**。
- **认证**：自定义头 `x-auth-token`（非 `Authorization: Bearer`），token 存于 localStorage 同名键。
- **账户模型**：支持游客（guest）自动注册，`guestUid` + `guestKey` 换取 `idToken`。
- **积分体系**：统一 "Integral"（积分），分 VIP 积分 / 套餐积分 / 每日免费积分；各业务线（图像/视频/音频/漫画/动作/视频编辑）独立计费端点，前端本地还有兜底估算公式。
- **供应商**：从 Webhook 端点可见接入 Alibaba、BytePlus、MiniMax、MuleRouter、Pollo 等第三方视频生成服务。
- **多语言**：34 个 locale，`localePrefix: as-needed`（默认英文无前缀）。

> ⚠️ 免责声明：本文档为对**前端**产物的静态分析。后端真实逻辑、数据库结构、风控策略无法从前端完全还原，标注为 `待验证` 的部分需以实际接口为准。
