# 05 — 积分消耗与计费机制

> 位置线索：`7747`（calculateIntegral 端点定义）、`8048`（音频积分）、`5142`（积分调用与兜底公式）、`6628`（账户面板与每日积分）、`9689`（账户 store）。

---

## 1. 积分体系总览 `已验证`

平台使用统一货币 **Integral（积分）**，但账户内分**三个独立积分池**：

| 字段 | 名称 | 用途 |
|------|------|------|
| `integral` | **主积分** | 通用消费（音频生成前只校验此字段） |
| `packageIntegral` | **套餐积分** | VIP 套餐附赠池 |
| `vipIntegral` | **VIP 积分** | VIP 专属池 |
| `dayFreeIntegral` | **每日免费积分** | 每日领取，24 小时过期 |

**生成前积分校验**（视频/图像/漫画/动作/视频编辑，`5142`）：
```js
const level = Number(model.vipLevel || 0);
if (level > 0 && (accountInfo.packageIntegral || 0) <= 0 && (accountInfo.vipIntegral || 0) <= 0)
  return void buyVipModal.open(level);    // 高等级模型需套餐/VIP积分
```
**音频生成校验**只比主积分：`if ((accountInfo.integral ?? 0) < required) return buyVipModal.open();`

> ⚠️ 说明：VIP **不免积分**。VIP 的作用是解锁 `vipLevel>0` 的高级模型 + 输出数量>1 + 更高的自定义音色额度。

## 3. 前端本地计费公式与兜底 `已验证`

平台**主计费在服务端**（`calculateIntegral` 返回数值），但前端存在若干**本地公式/固定值**：

### 3.1 漫画 fallback 估算公式（核心）`已验证`
位置：`5142`，`calculateIntegral` 的 `catch` 分支
```js
console.warn("Failed to calculate comic integral, fallback to estimate:", t);
X(Math.ceil(
  (model.integralFee || 20)
  * (1 + 0.2 * Math.max(0, (parseInt(comicPanels.replace(/\D+/g,""),10) || 4) - 4))
  * number
));
```
**解读**：
- 基础价 = 模型 `integralFee`（缺省 20）
- 面板数 ≤ 4 不加价；每多 1 个面板 **+20%**
- 再乘以输出数量 `number`
- 触发条件：服务端积分接口抛异常时

### 3.2 音效时长换算 `已验证`
```js
const length = Math.max(1, Math.round(audioDurationSec / 10));  // 10 秒/档，向上取整到 1
await calculateSoundEffectIntegral({ calculateSoundEffectIntegralRequest: { length } });
```
即**音效按 10 秒为单位的时长档计费**。

### 3.3 固定值规则 `已验证`
| 场景 | 值 | 位置 |
|------|-----|------|
| 变声（voice_changer） | **10** | `5142` |
| TTS 文本 < 2 字符 | **1** | `5142` |
| 每日免费积分 | **+100** | `9689` 弹窗 UI |
| 每日积分进度条上限 | **86400** 秒（24 小时） | `6628` |

### 3.4 音频积分分支完整逻辑 `已验证`
```js
if (mode === "tts") {
  if (text.trim().length >= 2) {
    const r = await calculateSpeechIntegral({ calculateSpeechIntegralRequest: { speech: text.trim() } });
    setAudioIntegral(r.data);
  } else setAudioIntegral(1);                       // < 2 字符 → 固定 1
}
else if (mode === "create_voice") {
  const r = await getCreateVoiceIntegral();  setAudioIntegral(r.data);
}
else if (mode === "create_music") {
  const r = await getCreateMusicIntegral();  setAudioIntegral(r.data);
}
else if (mode === "create_sfx") {
  const length = Math.max(1, Math.round(duration / 10));
  const r = await calculateSoundEffectIntegral({ calculateSoundEffectIntegralRequest: { length } });
  setAudioIntegral(r.data);
}
else if (mode === "voice_changer") {
  setAudioIntegral(10);                             // 固定 10
}
```

## 4. 模型级积分定价 `静态确认`

模型对象含 `integralFee` 字段（**基础积分价**），前端在**选中模型时立即用它显示**，随后异步调 `calculateIntegral` 覆盖为精确值：

```js
// 对口型：选中模型时
const m = lipSyncModels.find(x => String(x.id) === selectedId);
if (m && m.integralFee !== undefined) setLipSyncIntegral(m.integralFee);

// 数字人：选中模型时
const m = avatarModels.find(x => String(x.id) === selectedId);
if (m && m.integralFee !== undefined) setAvatarIntegral(m.integralFee);

// 漫画：fallback 公式的基础价
(model.integralFee || 20)
```

> 说明：模型列表（`/api/aiVideo/lipSyncModels`、`/api/aiVideo/talkingAvatarModels`、`/api/aiComic/models`）返回的对象带 `integralFee`。
> **✅ 已实测**：68 个模型的 `integralFee` 具体数值见 **[29-实测模型清单与积分定价.md](./29-实测模型清单与积分定价.md)**。
> 摘要：图像模型 1~45 积分；视频模型 25~225 积分（全部 `vipLevel=2`）。

## 5. 计费维度汇总 `已验证`

| 业务线 | 计费维度 |
|--------|---------|
| 图像 | modelId + resolution + quality + aspectRatio + **number（数量）** + **hasInputImage（是否有输入图）** |
| 视频 | modelId + **length（时长）** + resolution + aspectRatio + **enableAudio** + **number** + mode |
| 漫画 | modelId + **comicPanels（面板数）** + format + style + resolution + quality + aspectRatio + **number** + hasInputImage |
| 对口型 | modelId + video + audio + **audioType（预设/本地）** |
| 动作控制 | modelId + image + video（number 固定 1） |
| 数字人 | modelId + image + audio + **audioType** + speech + prompt + mode |
| 视频编辑 | modelId + 素材 + **length** + resolution + **enableAudio** + keepOriginalSound + characterOrientation + mode + **strength** |
| TTS | **speech 文本内容**（服务端按文本计费） |
| 音效 | **length（10 秒/档）** |
| 音乐 / 音色克隆 | 无参（服务端按账户状态返回固定值） |
| 变声 | **固定 10** |

## 8. 积分不足处理 `已验证`

统一模式（图像/视频/漫画/对口型/数字人/动作/视频编辑共 7+ 处）：
```js
if (data.code === -1) return void (
  accountInfo?.canAccessVip !== true
    ? (buyVipModal.open(),                              // 打开购买弹窗（默认订阅 tab）
       toast({ title: "reminder",
               description: "insufficientCredits" /* 积分不足 */,
               timeout: 3500, color: "warning" }))
    : buyVipModal.open(3)                               // VIP → 积分充值 tab
);
```

| 用户 | 行为 |
|------|------|
| 非 VIP | 打开购买弹窗 + "积分不足"提示 |
| VIP | 直接跳 `/pricing?tab=credits` |

## 10. 积分与 VIP 的关系 `已验证`

### 10.1 VIP 等级
```js
{ 1: "STANDARD", 2: "PREMIUM", 3: "DELUXE" }[vipLevel]
```
（模型卡片角标；`vipLevel` 为 `0` 时不显示角标，即免费模型）

### 10.2 VIP 特权
| 能力 | 免费 | VIP |
|------|------|-----|
| 基础模型（vipLevel=0） | ✅ | ✅ |
| 高级模型（vipLevel≥1） | ❌ | ✅（需套餐/VIP积分） |
| 输出数量 > 1 | ❌ | ✅ |
| 自定义音色额度 | 有限 | 更多 |
| 积分不足处理 | 引导订阅 | 引导充值 |

### 10.3 结论
- **VIP 不减免单次积分**（`calculateIntegral` 请求参数不含 VIP 字段，定价在服务端）。
- VIP 作用是：① 解锁高级模型；② 解锁多输出；③ 独立积分池；④ 更高音色额度。
- 普通用户仅有 `integral`（主积分）+ `dayFreeIntegral`（每日免费）。
