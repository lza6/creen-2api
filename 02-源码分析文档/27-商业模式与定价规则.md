## 2. 积分体系（核心规则）`已验证`

### 2.1 两种积分类型
| 类型 | 来源 | 累积性 | 有效期 |
|------|------|-------|--------|
| **方案订阅积分** | 套餐每月配额 | ❌ **不累积**（每周期重置为配额） | 周期结束即失效 |
| **积分包积分** | 单独购买的积分包 | ✅ **永久累积**（叠加） | **永不过期** |

### 2.2 消耗优先级 `已验证`
```
优先消耗【方案订阅积分】→ 再消耗【积分包积分】
```
> 目的：尽可能保留永不过期的积分包余额。

### 2.3 官方示例 `已验证`
> Sam 在 3 月 7 日订阅 Pro，获得 8,000 积分。到 4 月 1 日用了 5,000。4 月 7 日他的余额**刷新为 8,000**（不是 11,000）——方案积分会重置，不会累积。如果是积分包积分则会叠加。

> 付费订阅者在每次购买积分包时还会获得**等级奖励**——订阅等级越高奖励越多。**Ultra 等级最高 +20%**（相当于所有积分充值享 20% 折扣），**与积分包奖励叠加**。

## 4. 升级规则 `已验证`

### 4.1 立即生效 + 按比例补差价
> 升级会**立即生效**。收取旧方案与新方案之间的**按比例计算的差额**（由 Stripe 自动处理），新方案功能立即解锁。

### 4.2 积分补发公式 `已验证`
```
新增积分 = (新方案月度配额) − (本周期已用积分)
```
> **官方示例**：当前 Pro（8,000/月）已用 3,000 → 升级到 Max（20,000/月）
> 补发 = 20,000 − 3,000 = **17,000 积分**

### 4.3 账单周期锚点
- **方案等级升级**：账单日期**不变**（Stripe 保留周期锚点），下次扣费为新方案全额。
- **月付 → 年付**（例外）：收取「年付价 − 本周期已付月费」，**立即开启新年周期**，续约日期后移一年。
  > 例：Pro 年付 $174 − 已付 $29 = **$145**

---

## 5. 降级规则 `已验证`

> 降级在**下一个计费周期开始时**生效。在此之前可继续使用当前方案完整权益和积分。**不按比例退款**（已为现有服务付费）。
>
> 下次续期自动切换为低等级方案并按低价收费。可在 `/subscriptions` 取消已排期的降级。

---

## 6. 取消规则 `已验证`

### 6.1 两个独立订阅
> 方案订阅和积分包是**两个独立的订阅**——可单独取消任一个，或同时取消，**互不影响**。

### 6.2 取消后行为
| 类型 | 行为 |
|------|------|
| **方案订阅** | 月付访问至月末；年付至年末。到期后**未使用的方案积分重置为 0**，账户降为免费等级 |
| **积分包** | 当前周期结束后停止扣费；**余额中所有积分包积分永久保留** |

### 6.3 关键时限 `已验证`
> **请至少在续约日期前 5 天取消**，以避免下一次扣费。

### 6.4 恢复
> 在当前周期结束前**重新订阅**即可保持一切继续运作——**无需支付新费用**，当前计费周期继续运行。

## 10. 支付流程（据文案重建）`静态确认`

```
定价页 (/pricing)
 ├─ 选套餐（Spark/Studio/Atelier/Maestro）
 ├─ 选周期（Monthly / Annual）
 ├─ 选支付通道（Stripe / Dodo / Google / iOS）
 │    └─ 首次购买 → createSubscription(goodsId)
 │         Stripe: stripeCreateSubscription
 │         Dodo:   dodoCreateSubscription
 ├─ 已有订阅 → 判定升级/降级
 │    ├─ 升级 → upgradeSubscription(newGoodsId)  [立即生效 + 按比例补差价]
 │    └─ 降级 → downgradeSubscription(newGoodsId) [下周期生效]
 └─ 结果
      ├─ 成功 → /paySuccess（"恭喜，支付成功！"）
      └─ 失败 → /payFailed（"支付失败"）

订阅管理页 (/subscriptions)
 ├─ 查看 activePlan / activePack / creditsBalance
 ├─ 切换套餐（changePlan）
 ├─ 切换积分包（changeCreditsPack / switchPack）
 ├─ 取消（cancelSubscription / cancelCreditsSubscription）
 ├─ 恢复（resumeSubscription）
 ├─ 取消降级（cancelDowngrade）
 └─ 账单门户（billingPortal → Stripe）
```
