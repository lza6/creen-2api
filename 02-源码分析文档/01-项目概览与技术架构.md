## 2. 技术栈 `已验证`

- `transformRequest` / `xsrfCookieName` / `allowAbsoluteUrls` → axios v1.x。
- `createContext` + `useState` + `useLayoutEffect` → React 18 + StrictMode。

### 启动时认证握手 `静态确认`
位置：`6628` chunk `AuthProvider`
```
1. syncGuestInfo()                     // 读取/创建本地游客身份
2. getAccount({x-no-handle:true})      // 拉取账户信息
   ├─ code === "200"  → 成功，写入账户状态
   └─ 失败 → clearToken() → guestLogin()
3. guestLogin():
   - 从 localStorage 取 guestUid / guestKey
   - POST /api/auth/loginByGuest {authLoginByGuestRequest:{guestUid,guestKey}}
   - 成功 → setToken(idToken) → 重新 getAccount(true)
   - 失败 → clearGuestInfo() → reload()
```
游客创建（无本地身份时）：
```
initFinger() → createGuest() → 保存 guestUid/guestKey 到 localStorage
```

## 6. 前后端通信模型 `已验证`

- **同源代理**：请求 `baseURL` 为 `"/"`，即前端直接请求 `https://www.creen.ai/api/...`，由 Next.js rewrite / 反向代理转发到后端微服务。
- **OpenAPI server 占位**：`o2 = "http://localhost:9900"` 是 OpenAPI 代码生成器的默认 server，运行时被 `fY`（真实 basePath）覆盖。
- **超时**：默认 60 秒（`timeout:6e4`）。
- **内容类型**：`Content-Type: application/json`。
- **异步任务**：生成类接口返回 `resultId`，前端轮询 `getTaskStatus` / `checkJobStatus` / `getListTaskStatus`；第三方完成时经 **Webhook** 回调后端（见 07 文档）。
