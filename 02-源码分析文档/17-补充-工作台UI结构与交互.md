## 5. 上传交互 `已验证`

### 5.1 支持方式
- 点击上传（`handleXxxClick`）
- 拖放上传（`handleXxxDrop` / `handleGlobalFileDrop` / `handleSubTabFileDrop`）

### 5.2 上传状态流
```
选择文件 → status:"uploading"（本地预览 URL）
        → POST /api/upload/uploadTempFile
        → status:"success"（记录服务端 URL）
        → 失败：status:"fail"
```

### 5.3 图片数量限制
```js
const remaining = Math.max(0, 10 - current.length);   // 单次最多 10 张
for (const file of files.slice(0, remaining)) { ... }
```
模型级限制：`maxStandardImageInputCount ?? maxImageInputCount ?? 3`。

## 6. 处理人像识别（对口型）`已验证`

```
1. 上传视频 → 显示上传状态
2. 调 lipSyncFaceRecognition({ video }) → 返回 { faceData[], sessionId }
3. 若 faceData 为空 → toast "noFacesDetected"
4. 弹出选脸弹窗（selectFaceToLipSync）
5. 选脸后 confirm → 提交 createLipSync（带 sessionId + faceId）
```
