### 1.2 语言判定顺序 `已验证`
```js
function getCurrentLocale() {
  // 1) URL 路径前缀（如 /ja/create）
  for (const loc of LOCALES)
    if (pathname.startsWith(`/${loc}/`) || pathname === `/${loc}`) return loc;
  // 2) NEXT_LOCALE cookie
  const cookie = getCookie("NEXT_LOCALE");
  if (cookie && LOCALES.includes(cookie)) return cookie;
  // 3) navigator.language（取主语言）
  if (navigator.language) {
    const primary = navigator.language.split("-")[0];
    if (LOCALES.includes(primary)) return primary;
  }
  // 4) 默认
  return "en";
}
```

### 1.3 路由策略 `已验证`


## 4. 状态管理 `静态确认`

使用 **Zustand**，主要 store：

| Store | 内容 |
|-------|------|
| `authStore` | `accountInfo` / `isLoading` / `error`（`6628` AuthProvider） |
| `audioStore` | 音频 Tab 状态（模式、文本、音色、积分等） |
| `generateVideoStore` | 视频生成状态（模型、模式、时长、分辨率…） |
| 主题 store | 明暗主题（持久化到 localStorage） |
| 模型 store | 选中模型（`defaultImageModelId` / `defaultVideoModelId`） |

选择器 hook 形态：`(0, E1)()` 取 store、`(0, T4)()` 取 `accountInfo`、`(0, GD)()` 取全局模态控制器。
