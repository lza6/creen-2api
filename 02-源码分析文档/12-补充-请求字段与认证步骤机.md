## 2. 认证 UI 步骤机 `已验证`

`9689` 中的登录弹窗是一个**多步骤状态机**（状态变量 `G`）：

### 2.1 全部步骤状态
| 步骤 | 含义 | 返回行为 |
|------|------|---------|
| `login` | 登录表单 | — |
| `register-step1` | 注册第 1 步（邮箱+密码+Turnstile） | → `login` |
| `register-step2` | 注册第 2 步（6 位验证码） | → `register-step1` |
| `register-step3` | 注册第 3 步（昵称） | → `register-step2` |
| `register-success` | 注册成功页 | — |
| `forgot-step1` | 找回密码第 1 步（邮箱） | → `login` |
| `forgot-step2` | 找回密码第 2 步（验证码） | → `forgot-step1` |
| `forgot-step3` | 找回密码第 3 步（新密码） | → `forgot-step2` |

### 2.2 步骤流转 `已验证`
```js
// 注册
regSubmit 成功 → setStep("register-step2") + 启动 60s 倒计时
confirmReg 成功 → setStep("register-step3")
setNickname 成功 → setStep("register-success")

// 返回
"register-step1" → "login"
"register-step2" → "register-step1"
"forgot-step1"   → "login"
"forgot-step2"   → "forgot-step1"
"forgot-step3"   → "forgot-step2"
```

### 2.3 步骤标题 i18n key `已验证`
| 步骤 | key |
|------|-----|
| `register-step1` | `createAccountTitle` |
| `register-step2` | `verifyEmailTitle` |
| `register-step3` | `chooseNicknameTitle` |
| `register-success` | `welcome...` |
| `login` | `signIn` |

### 2.4 进度条
3 段进度条，`register-step1` 亮 1 段，`step2` 亮 2 段，`step3` 亮 3 段。

### 2.5 密码要求提示 `已验证`
- `passwordRequired`、`passwordRequirements`、`passwordsDoNotMatch`
- 邮箱错误：`invalidEmail`、`emailAlreadyRegistered`
- 凭据错误：`incorrectCredentials`
- 验证码错误：`incorrectCode`
- `verifyEmailSubtitle` 会拼接邮箱地址显示

### 2.6 倒计时
- 重发验证码：**60 秒**（`V(60)`），倒计时期间按钮禁用

## 4. 业务枚举全集（汇总）`已验证`

### 4.1 视频生成 mode
| 值 | 含义 |
|----|------|
| `"1"` | 文生视频 |
| `"2"` | 首尾帧生视频 |
| `"3"` | 参考图生视频 |

### 4.2 音频 audioType
| 值 | 含义 | 场景 |
|----|------|------|
| `1` | 本地上传 | 音频/对口型/数字人/变声 |
| `2` | 预设音色（轨 1） | 音频/对口型/数字人 |
| `3` | 预设音色（第二音轨） | 数字人 |

### 4.3 任务状态 status
| 值 | 字符串 | 含义 |
|----|-------|------|
| `2` | `"SUCCESS"` | 成功 |
| `3` | `"FAILED"` | 失败 |
| 其它 | — | 进行中 |

### 4.4 结果 code
| 值 | 含义 |
|----|------|
| `1` | 提交成功 |
| `-1` | 积分不足 |
| `-2` | 生成失败 |
| `-3` | 内容审核 / 任务进行中 |
| `-4` | 任务数超限 |
| `-5` | 操作过频 |
| `-6` | 自定义音色上限 |

### 4.5 VIP 等级
| vipLevel | 名称 |
|----------|------|
| 0 | 免费 |
| 1 | STANDARD |
| 2 | PREMIUM |
| 3 | DELUXE |

### 4.6 上传状态
`uploading` → `success` / `fail`

### 4.7 媒体类型限制
- 图片：`image/*`
- 视频：`video/*`（MP4/MOV/WEBM）
- 音频：`audio/mpeg`、`audio/mp3`、`audio/wav`、`audio/x-wav`、`audio/aac`、`audio/x-aac`
- 单次图片上限：**10 张**（`Math.max(0, 10 - current.length)`）
- 模型输入图上限：默认 **3 张**

### 4.8 时长/尺寸约束
- 视频宽度下限：**640**（`videoDimensionsMin640`）
- 视频宽高：受 `config.minVideoWidth` / `maxVideoWidth` 等约束
- SFX 时长档：**10 秒/档**
- 提示词长度：默认 **3000**（`promptLength` 可覆盖）
- 滚动时长范围：默认 `1` ~ `15`
