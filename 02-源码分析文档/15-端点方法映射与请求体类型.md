## 5. 直接 axios 调用（非 OpenAPI 生成）`已验证`

| 模块 | 文件 | 端点 | 写法 |
|------|------|------|------|
| Project API | `8048` (74973) | `/api/project/*` | `n.FH.post/get/put/delete` |
| AiComic | `5142` | `/api/aiComic/*` | `w.FH.post/get` / `w.uE.post` |
| AiExplore | `5142` | `/api/aiExplore/*` | `w.uE.get` |
| 图像创建 | `5142` | `/api/aiImage/create/v2` | `w.uE.post` |
| 上传 | `5142` | `/api/upload/uploadTempFile` | 辅助函数 `(0,N.Q)(file, path)` |

> 这些未走 OpenAPI 客户端，而是直接调用 axios 实例（`FH` = 带拦截器的实例，`uE` = 同类实例）。

## 6. Axios 实例别名对照 `静态确认`

在 `9689` 模块 `26865` 中导出：
| 符号 | 含义 |
|------|------|
| `uE` | axios 实例（主） |
| `FH` | 带方法的实例包装（`get/post/put/patch/delete`） |
| `pN` | `"x-no-handle"` 常量 |
| `$U` | toast 函数 |

各文件使用：
- `5142`：`w.uE` / `w.FH`
- `8048`：`n.FH` / `n.uE`
- `3866`、`7747`、`6628`：`cfg.uE`
