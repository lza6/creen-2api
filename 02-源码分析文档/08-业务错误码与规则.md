# 08 — 业务错误码与规则

> 位置线索：`9689`（axios 响应拦截器）、`5142`（业务码处理）、`6628`（认证错误消费）。

---

## 1. 两层错误码体系

平台存在**两套独立**的错误码：

### 1.1 传输层错误码（字符串，由 axios 拦截器处理）`已验证`

| code | 语义 | 前端行为 |
|------|------|---------|
| `"200"` | 成功 | 返回信封数据 |
| `"400"` | 参数错误 | toast（优先 `fieldErrors[0].message`），抛 `ApiError` |
| `"401"` | 未认证 | 清 token + 跳转 `/` + toast |
| `"403"` | 无权限 | toast "Access forbidden" |
| `"500"` | 服务端错误 | toast `msg`（带 `x-no-show-msg-handle` 则静默） |

### 1.2 业务层错误码（数字，在业务代码中判定）`已验证`

**生成类接口**在 `data.code` 中返回数字码：

| code | 语义 | 前端行为 |
|------|------|---------|
| `1` | **提交成功** | 显示成功 toast，记录 `resultId`，刷新项目列表 |
| `-1` | **积分不足** | 非 VIP → 打开购买弹窗 + "积分不足"提示；VIP → 跳积分充值 |
| `-2` | **生成失败** | toast `generateFailed`（danger） |
| `-3` | **内容安全 / 任务进行中** | toast 内容警告；音频场景为"已有生成任务进行中" |
| `-4` | **任务数超限** | toast `jobCountLimitError`；非 VIP/低 VIP → 打开升级弹窗 |
| `-5` | **操作过频** | toast `operationTooFrequent`（限流） |
| `-6` | **自定义音色上限** | toast `customVoiceLimitReached`，引导升级 VIP |

#### 业务码原文对照 `已验证`

```js
// -1 积分不足（5142，对口型示例）
if (-1 === j) return void (
  c?.canAccessVip !== true
    ? (x.open(), toast({ title: o("reminder"), description: o("insufficientCredits") || "Insufficient credits.", color: "warning" }))
    : x.open(3)   // VIP → 积分充值
);

// -2 生成失败
if (-2 === j) return void toast({ title: o("error"), description: o("generateFailed"), color: "danger" });

// -3 内容警告
if (-3 === j) return void toast({ title: o("reminder"), description: o("generateContentWarningError"), color: "warning" });

// -4 任务数超限
if (-4 === j) {
  toast({ title: o("reminder"), description: a("jobCountLimitError") || "Job count limit exceeded.", color: "warning" });
  (c?.canAccessVip !== true || (c?.vipLevel ?? "0") < "3") && x.open(2);
  return;
}

// -5 操作过频
if (-5 === b.code) return void toast({ title: x("reminder"), description: m("aiGenerator.errors.operationTooFrequent"), ... });

// -6 自定义音色上限
if (-6 === S?.code) {
  toast({ title: "reminder", description: t("customVoiceLimitReached") || "The current user has reached the maximum number of custom voices allowed. Upgrade to VIP to unlock more voice creation capacity.", ... });
  ...
}

// 1 提交成功
if (1 === b.code) { toast({ title: "reminder", description: x("taskSubmittedSuccessfully"), color: "success" }); ... }
```

## 2. 前端校验规则（提交前）`已验证`

生成前会做多重前置校验，任一失败即中断并提示：

### 2.1 身份校验
```js
if (!accountInfo || accountInfo.isGuest) return void loginModal.open();
```
**游客不能生成**，必须登录（但可浏览）。

### 2.2 模型 VIP 等级校验
```js
const level = Number(model.vipLevel || 0);
if (level > 0 && (accountInfo.packageIntegral || 0) <= 0 && (accountInfo.vipIntegral || 0) <= 0)
  return void buyVipModal.open(level);   // 需要对应等级 VIP
```
模型自带 `vipLevel`（0=免费，1/2/3=需 VIP），账户需有套餐积分或 VIP 积分。

### 2.3 积分余额校验
```js
if ((accountInfo.integral ?? 0) < requiredIntegral) return void buyVipModal.open();
```

### 2.4 输入内容校验
| 校验 | 提示 |
|------|------|
| 未选模型 | `pleaseSelectModel` |
| 需图片但未上传（`isSupportImage && !isSupportText`） | `imageRequired` |
| 需文本但为空 | 提示输入提示词 |
| 提示词超长 | 默认上限 3000 字符（`promptLength`） |
| 图片超数量 | "Maximum 3 images allowed"（`maxImages`） |
| 视频宽高不符 | `videoWidthTooSmall/TooLarge`、`videoHeightTooSmall/TooLarge` |
| 对口型音频时长 > 视频 | `lipSyncAudioDurationLimitError` |
| 缺少对口型视频/音频 | `lipSyncVideoRequired` / `lipSyncAudioRequired` |

## 3. 限流与频率控制 `静态确认`

| 机制 | 表现 |
|------|------|
| 操作过频 | 业务码 `-5`，toast `operationTooFrequent` |
| 任务数上限 | 业务码 `-4`，toast `jobCountLimitError` |
| 音频重复提交 | 业务码 `-3`，提示"已有生成任务进行中" |
| 积分计算防抖 | 图像 300ms / 视频 300ms / 对口型 500ms / 数字人 500ms |
| 前端按钮防重复 | `isGenerating` 标志位，生成中禁用按钮 |

> 服务端具体限流阈值（如每分钟请求数、并发任务数）无法从前端还原，标记 `待验证`。

## 4. 内容安全审核 `静态确认`

- 视频：`GET /api/aiVideo/checkInputSafe?input=xxx`（输入预检）
- 业务码 `-3` 表示内容被拦截，提示 `generateContentWarningError`
- 结果字段可能含 `errorMessage`

> 具体审核策略（关键词/模型审核）在服务端，`待验证`。

## 5. VIP 权限差异 `已验证`

VIP 等级：`1 = STANDARD`、`2 = PREMIUM`、`3 = DELUXE`（模型卡片角标）

| 能力 | 免费用户 | VIP |
|------|---------|-----|
| 基础模型（vipLevel=0） | ✅ | ✅ |
| 高级模型（vipLevel≥1） | ❌ 需套餐/VIP积分 | ✅ |
| 输出数量 > 1 | ❌ 跳 `/pricing` | ✅ |
| 每日免费积分 | ✅（登录后） | ✅ |
| 自定义音色 | 有限（超限码 -6） | 更多额度 |
| 积分不足处理 | 引导订阅 | 引导充值积分 |

### 输出数量限制 `已验证`
```js
onClick: () => {
  if (count > 1 && accountInfo?.canAccessVip !== true)
    return void window.open("/pricing", "_blank");
  setCount(count);
}
```
即**数量 > 1 是 VIP 专属**。

## 7. 异常兜底策略 `已验证`

| 场景 | 兜底 |
|------|------|
| 积分计算接口失败 | 图像返回 `0`；音频/视频保持上次值；漫画使用**本地估算公式** |
| 模型列表加载失败 | `console.warn`，列表为空 |
| 账户信息加载失败 | 清 token → 游客登录 → 失败则 reload |
| 上传失败 | 该项状态置 `fail` |
| 轮询超时（60 次） | 停止轮询（无显式失败提示） |
| 项目缓存失效 | `delete window.__cachedProjectList` |
