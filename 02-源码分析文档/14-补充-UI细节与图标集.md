## 9. 首页守卫逻辑 `已验证`

`page` 模块 `92813`：
```js
const s = () => {
  const account = useAccountInfo();
  const modal = useGlobalModal();
  const checked = useRef(false);
  useEffect(() => {
    if (!checked.current && account) {
      // 已登录（非游客且有 email）or 未登录 → 打开登录弹窗
      if ((account.isGuest !== true && account.email) || (checked.current = true, modal.open()));
      // 简化：游客/无 email 时自动 open()
    }
  }, [account, modal]);
  return null;
};
```
**含义**：首页对**游客或无邮箱用户**自动弹出登录/引导弹窗。
