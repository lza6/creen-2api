## 1. 生成任务总流程 `静态确认`

所有 AI 生成采用**异步任务**模型：

```
┌──────────┐   ①提交    ┌──────────┐  ②入队   ┌────────────┐
│  前端    │ ─────────> │  后端API │ ───────> │ 任务队列    │
│          │            │          │          │            │
│          │ <───────── │ 返回     │          └─────┬──────┘
│          │  resultId  │ code=1   │                │ ③调用第三方
│          │            └──────────┘                ▼
│          │                                 ┌────────────┐
│          │            ┌──────────┐  ⑤回调   │ 第三方服务  │
│          │            │ Webhook  │ <─────── │ (Alibaba/  │
│          │            │ 端点     │          │ BytePlus/  │
│          │            └────┬─────┘          │ MiniMax/   │
│          │                 │ 更新结果        │ Pollo/…)   │
│          │  ④轮询状态      ▼                └────────────┘
│          │ <──────────────── 任务状态查询
└──────────┘
```

### 步骤详解

**① 提交生成请求**
- 端点：`/api/aiImage/create/v2`、`/api/aiVideo/create/v2`、`/api/audio/create*`、`/api/aiComic/create` 等
- 请求体包装在类型键下，如 `{ aiVideoCreateV2Request: {...} }`

**② 后端返回任务**
```jsonc
{
  "code": 1,                 // 数字 1 = 提交成功
  "resultId": "abc123",      // 任务 ID
  "newProjectData": { "id": 456 },  // 若自动建项目
  "data": { ... }
}
```
前端判定：`if (data.code === 1 && data.resultId) { /* 成功 */ }`

**③ 后端调度第三方**（不可见，由 Webhook 端点推断供应商）

**④ 前端轮询状态**
- 音频：`POST /api/audio/getListTaskStatus { aiAudioCheckStatusRequest: { resultIds: [id] } }`
- 图像：`POST /api/aiImage/getListTaskStatus { aiImageCheckStatusRequest: {...} }`
- 视频：`POST /api/aiVideo/checkJobStatus { aiVideoCheckStatusRequest: {...} }`
- 单个：`GET /api/aiImage/getTaskStatus/{imageResultId}`、`GET /api/audio/getTaskStatus/{resultId}`

**⑤ 第三方回调后端**（Webhook，服务端↔服务端）

## 2. 轮询机制 `已验证`

音频轮询实现（`5142`，其它业务线同构）：

```js
const POLL_INTERVAL = 5000;   // 5 秒
const MAX_ATTEMPTS  = 60;     // 60 次 → 最长 5 分钟

let attempt = 0;
const timer = setInterval(async () => {
  if (++attempt > MAX_ATTEMPTS) return void clearInterval(timer);
  const item = (await api.getListTaskStatus({
    aiAudioCheckStatusRequest: { resultIds: [resultId] }
  })).data?.[0];
  if (!item) return;
  const status = String(item.status);
  if (status === "SUCCESS" || status === "2") {       // 成功
    clearInterval(timer);
    refreshAccountInfo();                             // 刷新积分
    onComplete?.();
  } else if (status === "FAILED" || status === "3") { // 失败
    clearInterval(timer);
    toast({ title: "error", description: item.errorMessage || "Audio generation failed", color: "danger" });
  }
}, POLL_INTERVAL);
```

### 任务状态枚举 `静态确认`

| 状态 | 数字 | 语义 |
|------|------|------|
| `SUCCESS` | `2` | 成功 |
| `FAILED` | `3` | 失败 |
| 其它 | `0`/`1` | 进行中（继续轮询） |

> 注意：状态既可能是字符串（`"SUCCESS"`），也可能是数字（`"2"`）——前端用 `String(status)` 统一后比较。

### 其它轮询超时 `静态确认`
- 视频任务：最大尝试次数同为 60 次（`if(++a>60) clearInterval`）。
- 前端另有大量 `setTimeout(..., 300/500)` 用于**积分计算的防抖**（非轮询），例如：
  - 图像积分：300ms 防抖
  - 视频积分：300ms 防抖
  - 对口型积分：500ms 防抖
  - 数字人积分：500ms 防抖

## 3. Webhook 回调端点 `已验证`

以下端点由**第三方服务 → 后端**调用，非用户前端调用：

| 端点 | 供应商 | 说明 |
|------|--------|------|
| `POST /api/aiVideo/alibabaWebhook` | 阿里云 | 通义万相等视频任务回调 |
| `POST /api/aiVideo/byteplusWebhook` | 火山引擎 BytePlus | Seedance 等视频回调 |
| `POST /api/aiVideo/miniMaxWebhook` | MiniMax | Hailuo 视频回调 |
| `POST /api/aiVideo/mulerouterWebhook` | MuleRouter | 路由聚合服务回调 |
| `POST /api/aiVideo/polloWebhook` | Pollo AI | 视频生成回调 |

### 请求体类型 `已验证`
- `alibabaWebhook` / `byteplusWebhook` / `miniMaxWebhook`：`body`（`application/json`）
- `mulerouterWebhook`：`webhookEventResponse`
- `polloWebhook`：`webhookResponse`

### 管理端点 `已验证`
`POST /api/aiVideo/admin/syncJobStatus` —— 携带 `x-admin-key` 头，用于管理员手动同步任务状态（body `aiVideoCheckStatusRequest`）。

> 这些 Webhook 端点的存在**证实**了平台后端聚合了多家第三方视频生成供应商（详见 06 文档）。

## 4. 各业务线提交流程 `静态确认`

### 4.1 图像生成
```
用户填 prompt / 选参考图 / 选模型 / 分辨率 / 数量
  → calculateIntegral（300ms 防抖）显示预计消耗
  → create/v2
  → 轮询 getListTaskStatus
  → 完成后刷新作品列表 + 账户积分
```
请求体（`aiImageCreateV2Request` 调用点）：
```js
{
  modelId, baseImage, imageUrls, prompt, resolution,
  quality, aspectRatio, number, permission, projectId, background
}
```

### 4.2 视频生成
请求体（`aiVideoCreateV2Request`，已还原）：
```js
{
  modelId: N.id,
  mode: C,                       // "1"文生/"2"首尾帧/"3"参考图转视频
  images: A.length ? A : undefined,
  videos: E.length ? E : undefined,
  audios: _.length ? _ : undefined,
  prompt: Z,
  resolution: V || undefined,
  length: Number(P),             // 时长（秒）
  aspectRatio: (...条件) && R || undefined,
  permission: G,
  enableAudio: D,
  projectId: i || undefined,
  number: B
}
```

### 4.3 对口型（Lip Sync）
```
1. 上传视频 → lipSyncFaceRecognition {video} → 返回 {faceData[], sessionId}
2. 选人脸 faceId + 音频（预设/本地）
3. lipSyncCalculateIntegral 预估积分（500ms 防抖）
4. createLipSync {modelId, video, audio, audioType, sessionId, faceId, projectId}
```
- `audioType`：`2`=预设音色，`1`=本地上传
- 校验：音频时长 ≤ 视频时长；视频宽高需在模型 `config.minVideoWidth~maxVideoWidth` 范围内

### 4.4 数字人（Talking Avatar）
```js
{ modelId, image, audio, audioType, speech, prompt, mode, projectId }
```
- `audioType`：`3`=预设（第一音轨），`2`=预设（第二音轨），`1`=本地上传

### 4.5 动作控制（Motion Control）
```js
{ modelId, image, video, prompt, number:1, permission:1, projectId }
```
（number 固定为 1）

### 4.6 视频编辑（Edit Video）
```js
{ projectId, modelId, videos, images, audios, prompt, length,
  resolution, enableAudio, type, keepOriginalSound,
  characterOrientation, mode, strength }
```
各可选字段取决于模型 `config` 是否声明（如 `config.supportKeepOriginalSound`）。

### 4.7 音频（5 种模式）`已验证`
模式 key：`tts`、`create_voice`、`create_music`、`create_sfx`、`voice_changer`

| 模式 | 创建端点 | 请求体 |
|------|---------|--------|
| TTS 语音 | `createSpeech` | `{projectId, audioType:2, audio:"1", name:"Speech", speech}` |
| 音色克隆 | `createVoice` | `{projectId, name:"My Voice", prompt, language:"eng", audioType?, audio?}` |
| 音乐生成 | `createMusic` | `{projectId, prompt, speech, name:"My Song", enableInstrumental, imageUrls}` |
| 音效 | `createSoundEffect` | `{projectId, prompt, name:"Sound Effect", length:5, enableLoop}` |
| 变声 | `createVoiceChanger` | `{projectId, name:"Voice Changer", audioType:1, audio, voiceType:1, voice:"1", enableRemoveBackgroundNoise}` |

### 4.8 漫画（Comic）
```js
{ modelId, comicPanels, comicFormat, comicStyle, resolution,
  quality, aspectRatio, number, hasInputImage }
```

## 6. 文件上传流程 `已验证`

统一上传入口：`POST /api/upload/uploadTempFile`（`multipart/form-data`，字段 `file`）

```js
const url = await upload(file, "/api/upload/uploadTempFile");  // 返回 URL 字符串
```
- 音频/视频时长探测：上传后用 `<audio>`/`<video>` 元素读取 `duration`。
- 图片限制：单次最多 10 张（`Math.max(0, 10 - current.length)`）。
- 上传状态：`uploading` → `success` / `fail`。

## 7. 前端 Tab / 子任务状态 `静态确认`

主工作台（`5142`）维护多套待处理数据与状态：

| 状态 | 用途 |
|------|------|
| `activeTab` | 主 Tab（image/video/audio/comic/motion_control/video_editor） |
| `activeVideoSubTab` | 视频子 Tab |
| `pendingVideoData` / `pendingImageData` / `pendingMediaData` | 待处理数据 |
| `pendingMotionData` / `pendingVideoEditorData` / `pendingLipSyncData` | 待处理数据 |
| `isAudioGenerating` / `isComicGenerating` / `isVideoGenerate` | 生成中标志 |
| `imageIntegral` / `videoIntegral` / `audioIntegral` / `comicIntegral` / `motionIntegral` / `videoEditorIntegral` | 各业务线预估积分 |

### 场景（scene）路由映射 `已验证`
URL query `?scene=xxx` 决定打开的 Tab：

| scene 值 | Tab |
|----------|-----|
| `text_to_image` / `image_to_image` / `temp_to_image` / `ai_image` / `image` | image |
| `text_to_video` / `image_to_video` / `temp_to_video` / `ai_video` / `video` / `lip_sync` / `talking_avatar` | video |
| `motion_control` | motion_control |
| `video_edit` / `video_editor` | video_editor |
| `create_audio` / `audio` | audio |
| `comic` / `ai_comic` | comic |

数字 scene 映射：`1/2/3 → video`，`6/8/9 → image`，`12 → motion_control`，`14 → video_editor`，`15/16 → video`，`17 → audio`。

`?model=xxx` 可直接指定模型。
